# База AniShiki

`00_anishiki_schema.sql` — вся схема аккаунта сайта: таблицы, индексы, RLS и
бакет аватаров. Файл снят с боевой базы и применим на чистом проекте целиком.

## Переезд с базы VPN-бота — выполнен

Раньше таблицы AniShiki делили проект Supabase с базой VPN-бота
(`users`, `subscriptions`, `payments`, …). Теперь у сайта свой проект
`zvvxrleubfqwnxcgzasy`, приложение ходит только туда.

Что перенесено: три строки `auth.users` вместе с `encrypted_password` и
соответствующие `auth.identities` (пароли остались рабочими — bcrypt-хэши
переносятся как есть), плюс `profiles`, `favorites`, `lists`, `ratings`,
`history`. Пустые на момент переезда `friendships`, `comments` и `activity`
перенесены как пустые.

Таблицы AniShiki в старом проекте намеренно **не удалены** — они лежат там
как страховка, пока новый проект не отработает какое-то время. Когда
понадобится их убрать, удалять надо только их, ничего из таблиц бота.

Таблицы VPN-бота в этих миграциях не участвуют и не изменяются.
