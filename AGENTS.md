# AGENTS.md

Документация для ИИ-агентов, работающих с этим репозиторием, живёт в
[CLAUDE.md](CLAUDE.md) — там команды, устройство проекта и гарантии, которые легко
сломать. Этот файл существует, потому что часть инструментов ищет именно `AGENTS.md`;
содержимое не дублируется намеренно, чтобы два описания не разъехались.
